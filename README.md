# Inkline エディタ (PWA)

行番号・検索置換・自動保存を備えた、テキストファイル専用の高機能エディタです。
Chromebookにインストールすると、Files appから「.txtファイルをこのアプリで開く」が
できるようになります(Chrome拡張機能ではなく、PWAとして動作します)。

## Chromebookへのインストール手順

### 1. ファイルをどこかに置く
このフォルダのファイル一式を、ローカルのWebサーバーか、GitHub Pages / Netlify などの
静的ホスティングに配置してください。PWAのインストールと `file_handlers` 連携には
HTTPS(または localhost)での配信が必須です。

簡単な方法の例(Python の簡易サーバーを使う場合、Linux(Crostini)が有効なChromebookで):

```
cd inkline-editor
python3 -m http.server 8000
```

その後、Chromeで `http://localhost:8000` を開きます。

### 2. PWAとしてインストール
1. Chromeでアプリを開く
2. アドレスバー右側の「インストール」アイコン(モニターに矢印のアイコン)をクリック
   → 表示されない場合は、右上の「⋮」メニュー→「Inklineをインストール」
3. インストールすると、ランチャーにアプリとして追加されます

### 3. Files appとの連携を確認
1. Files appを開く
2. 任意の `.txt` ファイルを右クリック
3. 「開く」→「Inkline」が選択肢に表示されればOK
4. 「常にInklineで開く」を選ぶと、ダブルクリックで直接開けるようになります

> file_handlers の反映にはインストール後、少し時間がかかったり
> 一度Chromeを再起動する必要がある場合があります。

## 主な機能
- シンタックスハイライト(JavaScript(TypeScript/JSX含む) / JSON / HTML・XML / CSS / Markdown / Shell / Python / YAML、拡張子から自動判定・外部依存なし)
- 自動インデント(改行時に直前行のインデントを継承、`{`などの直後ではさらに1段深く)
- 括弧・クォートの自動補完(`( [ { " ' `` `の入力で自動的に閉じ、選択中のテキストを囲むことも可能。閉じ文字の上書き入力・空ペアのBackspace一括削除にも対応)
- HTMLファイル(`.html` / `.htm`)限定の拡張機能
  - `<` `>` の自動補完(他言語では比較演算子として使うため対象外)
  - タグの自動クローズ(`<div>` まで入力すると `</div>` を自動挿入。`<br>` `<img>` などの空要素や、閉じタグ自体は対象外)
- コードエディター向けの編集機能
  - `Tab` / `Shift+Tab` でインデント・アウトデント(選択行をまとめて処理)
  - `Ctrl+/` で行コメントの切替(JavaScript/Shell/Python/YAMLは`//`または`#`、CSS/HTML/Markdownは`/* */`または`<!-- -->`でブロックコメント)
  - `Alt+↑` / `Alt+↓` で行の入れ替え(上下移動)
  - `Ctrl+D` で行の複製
- 音声入力(マイクボタンからWeb Speech APIで音声をテキスト化してカーソル位置に挿入。日本語(ja-JP)対応。オンライン接続が必要です)
- 行番号ガター表示
- 空白・タブ・改行の可視化(ツールバーの「space_bar」アイコンで切替。半角スペースは`·`、タブは矢印、行末は`↵`、全角スペースは背景色で強調表示)
- アウトライン表示(ツールバーの「toc」アイコン。Markdownの見出し、JavaScript/Python/Shellの関数・クラス定義を一覧表示してジャンプ)
- 行のブックマーク(`Ctrl+F2`で現在行の切替、`F2`/`Shift+F2`で次へ/前へジャンプ。ツールバーの「bookmark」アイコンから一覧表示・ジャンプも可能。タブごとに保持され、セッション復元時にも維持されます)
- 文字数・単語数・行数・カーソル位置のリアルタイム表示
- 検索・置換(次へ/前へ移動、すべて置換)
- 既存ファイルを開いている場合は自動保存(約0.9秒のデバウンス)
- 名前を付けて保存 / 新規ファイル
- ライト/ダークテーマ切替(設定は記憶されます)
- キーボードショートカット:
  - `Ctrl+S` 保存 / `Ctrl+Shift+S` 名前を付けて保存
  - `Ctrl+O` 開く
  - `Ctrl+N` 新規
  - `Ctrl+F` 検索・置換パネル表示
  - `Ctrl+F2` ブックマークの切替 / `F2` 次のブックマークへ / `Shift+F2` 前のブックマークへ

## 対応ファイル形式
`.txt` / `.md` / `.markdown` / `.csv` / `.json` / `.log` / `.html` / `.htm` / `.css` /
`.js` / `.mjs` / `.cjs` / `.jsx` / `.ts` / `.tsx` / `.xml` / `.svg` /
`.sh` / `.bash` / `.zsh` / `.py` / `.pyw` / `.yml` / `.yaml`

> 上記以外の拡張子でも、ファイル選択ダイアログで「すべてのファイル」を選べば
> テキストとして開けます(シンタックスハイライトは対象外のプレーン表示になります)。
